# Vietnam-war-a-battleship-game
This project was made as an assignment for my Web devolpment classes. The goal was to do 3 html's pages: the first being the menu where the user inserts their: name, class, and difficulty; The Second its the game itself, where the player needs to get all the soldiers and bases before his moral go to negative; And the last to show a leaderboad of players ordered by most points. 

It uses localStorage to preserve the data about players and their points, Regex to validate the user's name and an algorithm to sort the leaderboard.
